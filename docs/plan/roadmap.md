# Roadmap

Every item is tagged **Intelligence** (agent-doable with local tools) or
**Human** (needs people, accounts, money, consent or a public commitment).
Horizons describe readiness, not elapsed time.

## Short horizon — CV/GitHub readiness (this handoff)

| ID | Item | Owner |
|---|---|---|
| CADET-001..010 | Clear the defect queue, add verification, docs and capture harness | Intelligence |
| CADET-011 | Choose and apply a licence | Human |
| CADET-012 | Run the seven-day pilot with real applicants | Human |

## Mid horizon — after the pilot, still local-first

| Item | Owner | Why not now |
|---|---|---|
| Re-check every `verified` fact against its canonical URL for the new cycle | Human | Official pages may block automated fetching; a person must confirm |
| Decide and document a production backend host | Human | Requires an account and spending |
| Add ROTC paths as a first-class track | Intelligence (after a human chooses the source set) | Domain decision, not a coding decision |
| Deadline calendar with ICS export | Intelligence | Needs a verified cycle-specific date set before it can be honest |
| Local encrypted vault for uploaded documents | Intelligence | Needs a threat-model decision from the owner |

## Long horizon — optional next

| Item | Owner | Why not now |
|---|---|---|
| Real push notifications via a backend | Human + Intelligence | Needs accounts and infrastructure |
| Source-grounded assistant | Intelligence | Must never fabricate facts or predict admission chances |
| Second locale (e.g. ZH) | Intelligence | Needs a human translator to certify the copy |
| Public talk / demo video | Human | Requires publishing and distribution decisions |

## Stop line

The last agent-doable step is the deterministic walkthrough capture plus the
pilot handoff document. The next action after that is always Human: recruit the
cohort, obtain consent, and run the pilot.
